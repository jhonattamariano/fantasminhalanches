# Fantasminha Lanches · Cardápio digital

Cardápio digital da Fantasminha Lanches, com pedido online, taxa de entrega por região e painel para gerenciar preços, fotos e itens.

- `index.html`: cardápio para o cliente
- `admin.html`: painel de gestão (login pelo Supabase)
- `img/`: fotos iniciais dos lanches

Os itens, preços, acréscimos e taxas ficam no Supabase. Alterar o cardápio pelo painel não exige novo deploy.
